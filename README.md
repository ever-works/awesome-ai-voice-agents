## Open-Source Frameworks

- [Botpress](https://botpress.com/) - Botpress is an open-source conversational AI platform for building chat and voice assistants with a visual studio and developer SDK. It can be self-hosted or used via cloud. Licensed under AGPL-3.0. ([Read more](/details/botpress.md)) `Open Source` `Self-Hosted` `Free Plan` `API` `Visual Builder` `AGPL`
- [LiveKit Agents](https://livekit.io/agents) - LiveKit Agents is an open-source framework for building real-time voice AI agents that run on LiveKit's WebRTC infrastructure. It supports Python and Node.js, enabling developers to create server-side voice agents. The framework is free and open-source under Apache-2.0. ([Read more](/details/livekit-agents.md)) `Open Source` `Self-Hosted` `Free Plan` `API` `Real-Time` `WebRTC`
- [Pipecat](https://pipecat.ai/) - Pipecat is an open-source Python framework for building voice and multimodal conversational agents with a pipeline architecture. It integrates with various STT, LLM, and TTS providers and supports local and cloud deployment. Licensed under MIT. ([Read more](/details/pipecat.md)) `Open Source` `Self-Hosted` `Free Plan` `API` `Multimodal` `Python`
- [Rasa](https://rasa.com/) - Rasa is an open-source machine learning framework for building contextual voice and text assistants. It provides NLU, dialogue management, and integration connectors. The open-source edition is free under Apache-2.0. ([Read more](/details/rasa.md)) `Open Source` `Self-Hosted` `Free Plan` `API` `NLU` `Dialogue Management`
- [Vocode](https://vocode.dev/) - Vocode is an open-source library for building voice-based LLM applications, providing abstractions for telephony, STT, TTS, and conversation management. It supports Python and TypeScript and can be self-hosted. Licensed under MIT. ([Read more](/details/vocode.md)) `Open Source` `Self-Hosted` `Free Plan` `API` `Telephony` `Python`

## Speech Providers (STT/TTS)

- [Amazon Transcribe](https://aws.amazon.com/transcribe) - Amazon Transcribe is an automatic speech recognition service that converts speech to text with features like speaker identification and custom vocabularies. Part of AWS, pay-as-you-go with free tier. ([Read more](/details/amazon-transcribe.md)) `API` `Freemium` `STT` `Speaker Identification` `Custom Vocabulary` `AWS`
- [AssemblyAI](https://assemblyai.com/) - AssemblyAI offers speech-to-text APIs with high accuracy, speaker diarization, and audio intelligence features. It targets developers building transcription and voice analytics. Free tier and pay-as-you-go. ([Read more](/details/assemblyai.md)) `API` `Freemium` `STT` `Audio Intelligence` `Speaker Diarization`
- [Cartesia](https://cartesia.ai/) - Cartesia provides real-time speech synthesis and recognition models, including the Sonic TTS model, optimized for low-latency voice applications. They offer API access for developers building voice agents. Pricing is usage-based with a free tier. ([Read more](/details/cartesia.md)) `API` `AI-Powered` `Freemium` `TTS` `STT` `Low Latency`
- [Google Cloud Speech-to-Text](https://cloud.google.com/speech-to-text) - Google Cloud Speech-to-Text provides automatic speech recognition in over 125 languages with streaming and batch modes. It integrates with Google Cloud ecosystem. Pay-as-you-go with free tier. ([Read more](/details/google-cloud-speech-to-text.md)) `API` `Freemium` `STT` `Multilingual` `Streaming` `Google Cloud`
- [OpenAI Speech](https://openai.com/) - OpenAI provides Whisper for speech-to-text and TTS models via API, enabling developers to add voice capabilities to applications. Pricing is per-minute for Whisper and per-character for TTS. ([Read more](/details/openai-speech.md)) `API` `Paid` `STT` `TTS` `Whisper` `AI-Powered`

## Telephony & SIP

- [Plivo](https://plivo.com/) - Plivo offers voice APIs and SIP trunking for inbound and outbound calling, with global coverage and per-second billing. It targets developers building voice applications. Pay-as-you-go pricing. ([Read more](/details/plivo.md)) `API` `Paid` `SIP` `PSTN` `Global` `Per-Second Billing`
- [SignalWire](https://signalwire.com/) - SignalWire provides elastic SIP trunking, voice APIs, and a programmable communications platform built on FreeSWITCH. It supports self-hosted and cloud deployment. Usage-based pricing. ([Read more](/details/signalwire.md)) `API` `Paid` `SIP` `FreeSWITCH` `Self-Hosted` `Programmable Voice`
- [Telnyx](https://telnyx.com/) - Telnyx delivers voice APIs, SIP trunking, and a global private network for real-time communications. It offers per-second billing and programmable voice features. - [Twilio Voice](https://twilio.com/voice) - Twilio Voice provides programmable voice APIs for making, receiving, and controlling phone calls over SIP and PSTN. It is widely used for building voice applications and contact centers. Pay-as-you-go pricing. ([Read more](/details/twilio-voice.md)) `API` `Paid` `SIP` `PSTN` `Programmable Voice` `Global`
